# PriceTrail

Трекер цін супермаркетів з історією цін: пошук товарів, картки з цінами й акціями, графік зміни ціни, перевірка «завищених» акцій. Працює як сайт і встановлюється на телефон (PWA). Зараз підтримується АТБ-Маркет (неофіційно), згодом — інші магазини.

Сайт: https://fima02.github.io/pricetrail/

## Як це працює

```
Планувальник Windows (щодня 07:30) → scripts/daily.ps1 → scraper/scrape.js → site/data/*.json → git push → GitHub Actions → GitHub Pages
```

Ціни збираються **з домашнього комп'ютера**: сайт АТБ (Cloudflare) блокує запити з серверів GitHub (HTTP 403). GitHub лише публікує сайт після кожного push.

- **`scraper/scrape.js`** збирає каталог atbmarket.com окремо для кожного міста зі **`scraper/cities.js`**. Асортимент і ціни залежать від магазину, тому в кожному місті береться один магазин — з найбільшим асортиментом (вибір зберігається в **`scraper/stores.json`**, його можна змінити вручну або перевибрати: `node scraper/scrape.js --repick`). Одне місто — ~4 хв, два міста збираються паралельно.
  - лише одне місто: `node scraper/scrape.js --city Хмельницький`
- **`scraper/groups.js`** — розділи («надкатегорії») для товарів: беруться з меню atbmarket.com, плюс ручні відповідності для категорій, яких у меню немає. Товари без відповідності потрапляють у розділ «Інше» — тоді додайте категорію в `EXTRA`.
- **`scripts/daily.ps1`** — pull → збір → коміт → push. Журнал пишеться в `daily.log`.
- **`scripts/install-task.ps1`** — реєструє щоденне завдання «ATB Price» у Планувальнику завдань.
- **`site/data/cities.json`** — список міст з даними.
- **`site/data/compare/NN.json`** — ціни кожного товару в усіх містах (для порівняння на сторінці товару), розбиті за `id % 100`. Будує **`scraper/compare.js`** після кожного збору; вручну: `node scraper/compare.js`.
- **`site/data/cities/<місто>/products.json`** — поточний каталог міста (для пошуку і карток).
- **`site/data/cities/<місто>/changes.json`** — що змінилося в останньому зборі порівняно з попереднім днем (стрічка «Що змінилося»): зміни цін, нові й зниклі товари. Будує **`scraper/changes.js`**.
- **`site/data/cities/<місто>/history/NN.json`** — історія цін міста, розбита на 100 файлів за `id % 100`. Зберігаються лише **зміни**: `[дата, ціна]` або `[дата, ціна, ціна_без_акції]`; `[дата, null]` означає, що товар зник з каталогу.
- **`site/`** — статичний сайт на чистому JS без збірки. Графік намальовано вручну через SVG.
- **Обране і сповіщення** працюють без сервера: обране зберігається в браузері (`localStorage`), подешевшання видно на сторінці «Обране» і на значку ♥. Системні сповіщення надсилає service worker (`site/sw.js`) через Periodic Background Sync — це працює в Chrome/Edge, коли сайт встановлено як застосунок; браузер сам вирішує, як часто перевіряти (приблизно раз на день).

## Локальний запуск

```bash
npm install
npm run scrape   # зібрати ціни (~5–10 хв)
npm run serve    # відкрити сайт на http://localhost:3000
```

## Публікація на GitHub

1. Створіть репозиторій на GitHub і запуште проєкт.
2. **Settings → Pages → Source: GitHub Actions.**
3. Зареєструйте щоденний збір (один раз):
   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\install-task.ps1
   ```

Далі все працює саме: щодня комп'ютер збирає ціни й пушить їх, а GitHub оновлює сайт. Якщо комп'ютер о 07:30 вимкнений, збір запуститься, щойно його увімкнуть.

Видалити завдання: `Unregister-ScheduledTask -TaskName 'ATB Price'`.

## Обмеження

- Ціни беруться для одного магазину в кожному місті; в інших магазинах того ж міста асортимент і ціни можуть трохи відрізнятися.
- Історія накопичується від першого запуску.
- Якщо АТБ змінить верстку сайту, треба буде поправити `parseCards()` у парсері.
